# RNA-seq processing and differential expression

This folder contains the workflow that runs on raw 3′ QuantSeq sequencing archives (`.tar.gz`) and processes it to the gene- and TE-level count matrices, together with the R scripts for filtering and differential expression.

- **Input:** sequencing archives listed in `snakemake/scripts/tarballs_to_extract.txt`
- **Output:** deduplicated BAM files, RSEM count matrices and MultiQC reports

## Structure

```text
01_transcriptome_analysis/
├── config/
│   ├── config.yaml              # Parameters and data paths
│   └── samples_unique.tsv              # Sample sheet (generated by the pipeline)
├── snakemake/
│   ├── Snakefile                # Pipeline entry point
│   ├── rules/                   # One file per processing step (see below)
│   └── scripts/                 # Helper scripts (sample sheet, tarball list)
└── r_scripts/                   # Filtering and differential expression
```

## Processing pipeline

The Snakemake pipeline runs the following steps in order:

1. [Preprocessing](snakemake/rules/00_preprocessing.smk)
   Extracts each sequencing archive in a separate job and builds the sample sheet with `build_sample_sheet.py`. Every library gets a unique identifier (e.g. `299871_S8_1`), so sequencing tags that repeat across runs stay unambiguous.

2. [Trimming](snakemake/rules/01_trimming.smk`)
   Extracts the 12-nt UMI from read 2 with `umi_tools extract` (quality threshold Q20) and places it in the read 1, then trims adapters and poly(A)/poly(X) tails and discards reads that are too short and bad quality. 

3. ([Quality control](snakemake/rules/02_qc.smk))
   Runs FastQC on trimmed reads and aligned BAM files and combines the results with MultiQC.

4. [Alignment](snakemake/rules/03_alignment.smk`)
   Aligns reads to the TAIR10 genome with `<aligner>`. The annotation lists every TE twice, in sense and antisense orientation (antisense features end in `_OP`), so both strands of each TE are quantified alongside protein-coding genes.

5. [Deduplication](snakemake/rules/04_deduplication.smk)
   Removes PCR duplicates with `umi_tools dedup` based on UMI and mapping position, and applies the same read-level filtering to the transcriptome alignments.

6. [Quantification](snakemake/rules/05_quantification.smk)
   Quantifies genes and TEs with RSEM on the deduplicated transcriptome alignments, producing raw counts and normalised abundances.

## Running the pipeline

From the `snakemake/` folder, check the planned jobs first, then submit to SLURM:

```bash
snakemake -n --quiet rules
snakemake --executor slurm --jobs 100 --retries 1
```
