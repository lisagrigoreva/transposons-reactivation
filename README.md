## Transcriptome Analysis of F1 *Arabidopsis thaliana* Crosses

This repository contains automated Snakemake pipelines for processing 3′ QuantSeq RNA-seq data from F1 *Arabidopsis thaliana* crosses. The workflow handles the processing from raw compressed sequencing archives to gene- and transposable element (TE)-level count matrices.

#### Biological Background

This project investigates parental effects and trans- and cis- regulation of TE expression across F1 hybrid transcriptomes generated from the *ddm1* (*decrease in DNA methylation 1*) mutant alongside wild-type (WT) controls in *Arabidopsis thaliana*. All crosses share a maternal Columbia-0 (Col-0) genetic background and are pollinated by distinct natural accessions.

The experimental design consists of two sets of data:
1. **Mutant background:** Col-0 *ddm1* × natural accession
2. **Wild-type background:** Col-0 DDM1 (WT) × natural accession


#### RNA-SeqPipeline

The core analysis is done by  [Snakemake](https://snakemake.readthedocs.io/) and stored in  `01_transcriptome_analysis/snakemake/rules/`. Reads are processed through the following rules:

1. `00_preprocessing.smk`  
   Parses raw tarballs and constructs a unified sample manifest using `build_sample_sheet.py`. Generates unambiguous identifiers (e.g., `299871_S8_1`, combining run ID, line number, and replicate index) to resolve duplicate sequencing tags.

2. `01_trimming.smk`  
   Executes sequential read trimming for QuantSeq:  
   - UMI extraction from read 2 (R2) followed by quality filtering.  
   - Adapter trimming, poly(X) tail removal, and minimum-length read filtering.

3. `02_qc.smk`  
   Runs quality control diagnostics using FastQC on both post-trimming FASTQ files and post-alignment BAM records to track library complexity and adapter depletion.

4. `03_alignment.smk`  
   Maps trimmed reads against the reference genome. To capture TEs which tend to be expressed from the opposite to the annotation strand, we create a reference GFF contains dual annotations for transposable elements, enabling simultaneous quantification of sense and antisense TE transcripts alongside standard gene models.

5. `04_deduplication.smk`  
   Identifies and collapses PCR duplicates using `umi_tools dedup` based on genomic coordinates, subsequently filtering duplicate entries out of the transcriptome-aligned alignments based on their read IDs.

6. `05_quantification.smk`  
   Quantifies final expression levels at both gene and TE resolution using RSEM on the deduplicated transcriptome alignments to produce raw count and normalized abundance matrices.

#### Quality Control & Identity Verification

To prevent misleading downstream conclusions caused by maternal self-fertilization or accidental pollen contamination, all sequenced individuals undergo genetic validation:
- **Variant Calling:** Identification of sample SNPs from aligned reads to confirm parental alleles.
- **IBD Painting :** Determination of identity-by-descent haplotypes across chromosomes to verify expected 1:1 parental genome contribution and filter out selfed Col-0 plants.
